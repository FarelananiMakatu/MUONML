# MUONML
This is Farelanani Makatu's (2577391) GitHub to store the code used to produced the ML algorithm studied and analysed in her Honours' report.

The .csv files included in this repository are the data files used for the ML, before and after the cuts have been applied (been labelled accordingly). The .ipynb files include the ML NN code used to present the results shown in the report - one for when B & D hadrons are signal, another for when B hadrons are the only signal considered and another when vice versa. The code was adjusted to work on Google Colab as all the results were run through there but adjustments on how the code reads the data files (.csv) can be made so that the Python code works on other software.
